OfficialGelo14 Website

Files:

- style.css — design, layout, responsive styling
- script.js — mobile navigation and scroll animations

Workflow:
Edit in Visual Studio Code → test locally → upload/commit to GitHub → Cloudflare automatically deploys the updated version.

The website is designed to use free hosting through GitHub + Cloudflare Workers/Pages infrastructure, with the existing custom domain connected separately.
