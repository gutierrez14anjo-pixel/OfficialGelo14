OFFICIALGELO14 WEBSITE

This version preserves the requested OfficialGelo14 visual direction:
- realistic sky/sea-inspired background
- translucent glass navigation and panels
- outlined logo and important headings
- bright blue/white aesthetic
- subtle clouds and birds
- responsive mobile layout
- separate HTML, CSS, and JavaScript files

Open the folder in Visual Studio Code:
1. File > Open Folder
2. Select OfficialGelo14-Website
3. Open index.html
4. Use Live Server if installed, or open index.html directly in a browser.

The background currently uses a remote image URL so the folder remains lightweight. You can later replace it with the exact final background asset.
